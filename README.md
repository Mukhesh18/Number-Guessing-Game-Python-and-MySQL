'Number Guessing Game' with MySQL Leaderboard is an interactive Python console application featuring a number guessing game with dynamic hot-and-cold hints. It integrates with a MySQL database to securely save player stats, track performance, and display top-score leaderboards.

This was built for my 12th Grade Computer Science Project Report.

The system must require it to have Windows OS, Python and MySQL to run the program.

First, ensure you have Python and the mysql-connector-python package installed along with a running MySQL server. Update the database credentials in the get_connection() function if needed, then simply run the script using python filename.py in your terminal to start playing!!
